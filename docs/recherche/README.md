# Les recherches sur le ping-pong

Sami (2/11/2026) : le cadrage, comme la cuisine : le modèle, la règle à battre, un prompt de recherche métier, un
glossaire et les questions. Ce dossier rassemble ce que disent les sources publiées et ce qu'elles ne disent pas.

À lire dans cet ordre :

1. [`../modele.md`](../modele.md) : le modèle, la règle simple, les mesures, ce qu'on prend de la lib ;
2. [chiffres.md](chiffres.md) : chaque chiffre, sa source et jusqu'où elle a été lue, puis les calculs de cadrage ; [autojeu.md](autojeu.md) prend la suite des mesures le 4/11/2026, `chiffres.md` étant presque plein ;
3. [glossaire.md](glossaire.md) : les mots du jeu et de la physique, et leur nom dans le code ;
4. [questions.md](questions.md) : ce qui reste à trancher, pour Sami et pour un entraîneur, chaque fois avec une
   recommandation ;
5. [prompt.md](prompt.md) : le prompt d'une recherche qui viserait ce qu'on n'a pas trouvé.

**La règle.** Un chiffre a sa source, ou il est écrit comme une hypothèse avec sa question. Un chiffre lu seulement dans un
résumé le dit, avec son statut, et se relit avant de décider quoi que ce soit. La recherche du 2/11 a lu dans le texte les
Lois de l'ITTF, Conti et al. 2026 (Sony AI), une part de Gossard et al. 2026 et Glynn et al. ; le reste vient de résumés ou
d'extraits, et plusieurs pages ont refusé la lecture.
